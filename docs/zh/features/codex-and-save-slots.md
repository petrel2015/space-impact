# 图鉴与三档存档

敌人图鉴 + 道具图鉴（未遭遇为剪影）、三档浏览器本地存档与续玩。
English version: [Codex & Save Slots](../../en/features/codex-and-save-slots.md).

## 图鉴（敌人 + 道具）

两个分页——**敌人**（`data/enemies.json` 全部 27 条）与**道具**（10 种
拾取物）。条目初始为暗色剪影加 `???` 名称和「首次出现于第 N 关」提示；
在游戏中真正遭遇即解锁（敌人出现在场上即算，道具拾取即算）。解锁后的
敌人卡片展示实时数值——血量、得分、速度、移动方式、攻击方式、攻击
间隔、弹速——以及双语一句话评价；道具卡片展示效果说明与评价。

### 设计决策

- **数值零复制。** 图鉴渲染时直接读*已编译*的 `enemies.json` defs，
  数据包一改图鉴即同步。`data/codex.json` 只存展示内容：敌人的
  `{en, zh}` 名称/评价，道具的名称/效果说明/评价。自动演示
  （`?demo`）**不**点亮图鉴。
- **攻击/移动文案是生成的，不是手写的。** `attack + attackParams`
  （含 `cycle` 子攻击与 `spawn` 引用——会解析为被召唤敌人的本地化
  名称）套 i18n 模板（`atkFan`、`mvDive` 等）拼出。27 条双语描述随
  数据自动保持一致；新增攻击类型缺模板时完备性测试直接失败。
- **「攻击力」是脚注，不是属性。** 所有敌方子弹 1 点伤害、碰撞 2 点
  伤害，全局恒定——按敌人写伤害数值等于编造。弹窗脚注同时记录周目
  加成（血量 ×1.4、速度 ×1.12）。
- **发现状态**存于 `localStorage`（`si-codex-v1`），按浏览器记录。
  「首次出现」提示在加载内置关卡时快照计算，上传自定义关卡不会改写。
- `enemies.json` 里新增但没有图鉴词条的自定义敌人优雅降级：名称显示
  id，数值照常渲染。

### 入口

- 首页：「开始游戏」旁的「图鉴」按钮。
- 暂停菜单（手机与电脑一致）：「图鉴」在暂停层上打开弹窗。

## 三档存档

槽位存**关卡边界快照**——与 `advanceLevel()` 交给 `startLevel()` 的
carry 完全同构：

```json
{ "v": 1, "levelId": 5, "loop": 1, "difficulty": "tight",
  "carry": { "score": 12345, "lives": 2, "weaponLevel": 3,
             "missiles": 8, "special": 2, "maxHp": 6 },
  "savedAt": 1700000000000 }
```

续玩时恢复难度预设并调用 `startLevel(idx, loop, carry)`；有限弹药
库存按该关重新计算。中途暂停保存的，续玩从该关开头带保存属性重打
（弹幕游戏存关内位置意义不大）。

- 键：`si-save-1/2/3`。JSON 损坏或版本未知的槽位读作空档；引用自定义
  （上传）关卡 id 的槽位显示「关卡数据缺失」，可删除。
- 暂停菜单 →「保存进度」打开三档选择器（点击即覆盖保存，摘要与时间
  就地刷新）。
- 首页 →「继续游戏」（仅在有存档时出现）以载入模式打开同一选择器；
  每个非空档位带删除按钮。

## 文件

| 文件 | 职责 |
|------|------|
| `data/codex.json` | 双语展示内容（唯一数据源） |
| `js/codex.js` | 发现状态、持久化、图鉴弹窗渲染 |
| `js/save.js` | 槽位存储 + 保存/载入选择器弹窗 |
| `js/app.js` | 数据加载、`firstSeen` 快照、发现钩子、入口接线 |
| `test/codex-test.js` | 内容对齐、模板覆盖、排序、持久化 |
| `test/save-test.js` | 槽位往返、隔离、损坏容错 |
| `test/codex-ui-test.js` | jsdom 端到端：解锁、保存、续玩、删除 |
