# 隐私

游戏存了什么、和谁通信——本文逐条对照源码写成，不是模板套话。
English version: [Privacy](../en/privacy.md).

## 概要

空间大战完全在你的浏览器里运行。**没有分析、没有遥测、没有第三方
请求。** 唯一的网络流量是页面加载自己的游戏数据。它记住你的一切都
在浏览器 `localStorage` 里，内容只有设置和最高分。

## 本地存储（localStorage）

游戏只写以下 7 个键，全部挂在页面同源下：

| 键 | 值 | 用途 | 生命周期 |
|----|----|------|----------|
| `si-lang` | `en` / `zh` | 界面语言 | 直到清除站点数据 |
| `si-theme` | `retro` / `night` / `paper` | 主题 | 直到清除站点数据 |
| `si-sound` | `1` / `0` | 音效开关 | 直到清除站点数据 |
| `si-hiscore` | 数字 | 历史最高分 | 直到清除站点数据 |
| `si-autofire-v2` | `1` / `0` | 自动连发开关 | 直到清除站点数据 |
| `si-aimline` | `1` / `0` | 瞄准虚线开关 | 直到清除站点数据 |
| `si-difficulty` | `casual` / `standard` / `tight` / `hardcore` | 难度档位 | 直到清除站点数据 |

不存储、不传输任何个人数据、标识符或游戏行为遥测。`localStorage`
不可用时（隐私模式、被禁），游戏静默回退默认值——不会坏，也什么都不记。

## 网络行为

对照源码核实的完整运行时网络活动清单：

1. **加载时的同源数据请求：** `data/enemies.json`、
   `data/levels.json` 与 14 个 `data/levels/level*.json`
   （带 `cache: 'no-cache'`）。
2. **同源静态资源：** 页面加载的 CSS/JS/图片，含两张收款码 PNG
   （`donate/alipay-qr.png`、`donate/wechat-qr.png`，预加载为了让
   捐赠弹窗秒开）。
3. **支付宝 App 唤起（仅手机、仅点击时）：** 在手机上点支付宝捐赠
   按钮时，页面尝试通过 `alipays://` URL scheme 拉起支付宝 App；
   1.5 秒内没反应就回退为展示二维码弹窗。这是代码库里唯一的对外
   URL，且只在你明确点击时发生。

**没有**分析/埋点脚本、没有字体/CDN 外链、没有广告 SDK、没有对任何
API 的请求、没有 Cookie。已加载的当前标签页内游戏离线照常可玩
（离线的限制见 FAQ）。

## 自定义关卡

你上传的关卡 JSON 由浏览器本地读取（`File.text()`）并在内存中编译。
它**不会被传到任何地方**，关闭标签页即消失。

## 声音

所有音效由 WebAudio 在浏览器内合成（方波）。不下载音频文件，也不录
音——从不请求麦克风。游戏不请求任何权限（相机、定位、通知、剪贴板
都没有）。

## 托管方说明

如果你玩的是 GitHub Pages 上的官方演示，GitHub（托管方）能在服务器
日志里看到 HTTP 请求，你的浏览器也会发送标准头（IP、User Agent）。
这是普通网站托管的固有行为，不在本项目控制范围内——游戏本身除了拉
取自己的文件外不发送任何东西。自行托管该目录即可完全掌控。
