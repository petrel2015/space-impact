# 玩法指南

怎么玩、怎么配置空间大战。游戏内容清单见 [README](../../README.zh.md)；
出了问题先看[故障排查](./troubleshooting.md)。English version:
[Playing Guide](../en/usage.md).

## 开始游戏

1. 打开[在线演示](https://petrel2015.github.io/space-impact/)——或在本地
   起服务（`python3 -m http.server 8000`，访问
   `http://localhost:8000/`）。
2. 可先在右上角 **设置 ⚙** 弹层里选难度/主题/音效/自动连发/瞄准虚线
   （见下文）。
3. 点 **开始游戏**（或按 `Enter`）。按钮在关卡数据加载完成前保持禁用——
   网络慢时需要等一下；加载失败会变成错误提示并出现 **重试** 按钮。

默认从第 1 关开始（`?level=N` 可强制指定）。击杀最终 Boss 即过关；
第 14 关后战役回到第 1 关循环，敌人更强，分数与强化保留。

## 操作

| 操作 | 键盘 | 触屏 |
|------|------|------|
| 移动 | 方向键 / WASD | 左下十字键 |
| 射击 | 空格 / J（默认点按单发） | FIRE 键 |
| 大招激光 | K / X | BOMB 键 |
| 暂停 / 继续 | P / Esc | ⏸ 键（LCD 右上角） |
| 瞄准虚线 开/关 | L | 设置 ⚙ |
| 开始 / 重试 | Enter | — |

- **默认点射：** 每按一次 FIRE 恰好发一轮。设置里打开 **自动连发**
  （会记忆）即可按住连射。
- **大招激光：** 需要至少 1 格 ⚡ 能量（上限 5）。清空全屏敌方子弹，
  对 Boss 造成 30 点、其他敌人 10 点伤害。
- 虚拟按键在触摸设备、手机/平板尺寸窗口自动出现，也可用 `?touch=1`
  强制显示。

## 难度档位

在设置 ⚙ 里选择（跑局之间随时改）；按浏览器记忆。

| 档位 | 生命数 | 血量上限 | 弹药 | 敌人强度 |
|------|--------|----------|------|----------|
| 轻松 | 4 | 10 | **无限** | ×0.8 |
| 标准（默认） | 3 | 8 | 基数 60 + 关卡时长×1.6/秒 | ×1.0 |
| 紧凑 | 3 | 6 | 基数 40 + 关卡时长×1.0/秒 | ×1.15 |
| 硬核 | 2 | 4 | 基数 30 + 关卡时长×0.6/秒 | ×1.3 |

弹药规则（标准档起）：

- 一**轮齐射**消耗 **1 发**，与炮管数无关（火力 3 级三管齐发仍是
  1 发）。
- 开局弹药量按关卡时长折算（180 秒的关在标准档为 60 + 1.6×180 ≈
  348 发；HUD 显示确切数字）。
- 每次击杀敌人**回收** 2 发（标准档）或 1 发（紧凑/硬核）。
- 导弹是**独立弹药池**，不占子弹库存。
- 打到 0 发时扳机打空——HUD 数字就是提示；瞄准虚线帮你别浪费子弹。

每进入新关卡都会按该关时长发放一份新弹药。损命会重置火力等级和导
弹，但不动弹药池。

战役循环（第 14 关后）敌人每圈：血量 +40%、速度 +12%、开火快 10%。

## 道具

掉落物向左漂移，撞上即拾取。

| 道具 | 效果 |
|------|------|
| **P** 火力 | 火力等级 +1（上限 3：1→2→3 管）。满级时改为 +200 分 |
| **S** 散弹 | 12 秒三向斜射散弹 |
| **L** 激光 | 10 秒穿透激光（穿敌、硬吃子弹对消） |
| **+** 回血 | +2 HP（不超过上限） |
| **E** 能量 | +1 格大招能量（上限 5） |
| **G** 护盾 | 吸收接下来 3 次命中 |
| **M** 导弹 | +12 发追踪导弹（上限 20）——高伤害（普通弹 3 倍）、自动锁定前方最近敌人、直接穿过敌方子弹 |
| **B** 回旋镖 | 10 秒回旋镖弹幕——飞出后折返回你的航线，去、回两程均穿透伤害，途中还会削掉敌方子弹 |
| **W** 僚机 | +1 台护航小机（上限 2），随每次开火平射——发射导弹时同样齐射；坠机清空，跨关与存档保留 |
| **1UP** 备用机 | +1 条命（上限 5）；满编时改为 +500 分 |

Boss 被击杀必掉回血 + 能量；中 Boss 必掉回血。损命会把火力重置为
1 级并清空导弹库存与僚机。

## 瞄准虚线

一条淡淡的流动虚线（开关：**L** 或设置 ⚙）实时预示下一轮弹道——每
根炮管一条射线，散弹模式连角度都有——命中第一个敌人处有闪烁十字标
记。它与真实弹道共用引擎里同一个射线函数，永远一致。纯视觉提示：
不消耗、不发射任何东西。

## 暂停与设置

- P/Esc 或 ⏸ 键暂停；浮层里可 继续 / 重新开始 / 主菜单。
- 游戏中打开右上角设置 ⚙ 会**自动暂停**；切走标签页同样自动暂停。
- 设置全部记忆：难度、主题、音效、自动连发、瞄准虚线（确切存储键
  见[隐私](./privacy.md)）。
- 顶栏按钮一键切换 中文/EN，选择会被记住。

## 自定义关卡

无需服务器、无需提交仓库：

1. 开始界面点 **下载关卡模板** —— 得到
   `space-impact-level-template.json`，一个可直接玩的小示例，`_help`
   字段写明每个键的用法。
2. 编辑 `events`（时间线），敌人 id 取自 `data/enemies.json`
   （完整字段说明见 [README](../../README.zh.md#扩展游戏)）。
3. 回到开始界面点 **上传关卡 JSON** 选择文件。关卡即刻通过校验、
   编译并开打。

规则：数字 `id`（缺省默认 90；建议用 90+ 避开内置关卡）、`events[]`
按 `t` 排序、至少一个 `boss` 事件（击杀即过关）。上传与之前相同 id
的关卡会替换它。坏文件会显示双语错误——见下表。上传的关卡只在当前
页面会话内存在。

## URL 参数

| 参数 | 作用 |
|------|------|
| `?lang=zh` / `?lang=en` | 指定语言 |
| `?theme=retro` / `night` / `paper` | 指定主题 |
| `?touch=1` | 桌面端显示触屏按键 |
| `?autostart=1` | 加载后自动开始 |
| `?demo=1` | 自动驾驶演示（配合 `?autostart=1`） |
| `?paused=1` | 打开即暂停（测试暂停界面） |
| `?aim=0` / `?aim=1` | 强制关闭/开启瞄准虚线 |
| `?level=14` | 从指定关卡开始（1–14） |

## 错误信息

所有数据错误都是双语的（跟随界面语言），并点名具体元凶：

| 情形 | 行为 |
|------|------|
| 通过 `file://` 打开页面 | 「游戏数据加载失败」+ 说明 `python3 -m http.server` 的提示；**重试** 按钮重新加载 |
| 关卡引用未知怪物 | `关卡「X」引用了未知怪物「Y」`——加载失败，提供重试 |
| 怪物引用未知精灵/移动/攻击 | 信息中点名（`errSpriteRef` / `errMovement` / `errAttack`） |
| 关卡文件格式错误 | `关卡文件「X」格式错误（需要数字 id 和 events 数组）` |
| 上传的文件有 JSON 语法错误 | 状态行显示浏览器解析错误；其他功能不受影响 |
| JS 运行时错误 | 在页面状态区就地显示，带文件与行号 |
