# 故障排查

真实故障模式，按出现频率粗略排序。English version:
[Troubleshooting](../en/troubleshooting.md). 这里解决不了就
[提 Issue](https://github.com/petrel2015/space-impact/issues)，附上：
浏览器 + 版本、完整 URL（含参数）、你做了什么、状态行说了什么
（开始界面截图很有用）。

## 开始界面提示「游戏数据加载失败」/ "Failed to load game data"

| 症状 | 原因 | 解决 |
|------|------|------|
| 双击 `index.html` 打开（URL 以 `file://` 开头） | 浏览器禁止 `file://` 页面 fetch 本地 JSON | 起服务：仓库目录里 `python3 -m http.server 8000`，访问 `http://localhost:8000/`——错误信息本身就写明了这一点 |
| 已经用 HTTP 伺服仍失败 | 某个数据包拿不到（404/500）或服务器截断了 JSON | 看 Network 面板里标红的请求；状态行会点名失败的文件与 HTTP 状态码 |
| 改内容时改坏了 JSON | 语法错误或引用笔误 | `node test/data-test.js` 会打印确切的出错条目；修好或还原 |

**重试** 按钮会重新加载——不用刷新页面。

## Start 按钮一直是灰色

按钮只有在 `data/enemies.json` + `data/levels.json` + 全部关卡文件
加载并编译完成后才启用。首次访问需要几个请求；如果一直不启用，说明
加载失败了——看按钮下方的状态行（会显示错误），按上一节处理。这是
保护逻辑不是 bug：没有内容游戏开不了场。

## 没有声音

- 浏览器要求用户手势后才允许出声。第一次点击/按键/触摸即解锁；如果
  你用 `?autostart=1` 开局且从未交互过，先随便点一下。
- 检查 设置 ⚙ → 音效 是 ON（记忆在 `si-sound`）。
- 系统级静音 / iOS 静音开关会静音 WebAudio。

## 触屏按键不出现

出现条件：设备是粗指针（真触屏），**或** 窗口宽 ≤ 560px，**或** 你
至少摸过一次屏幕，**或** URL 带 `?touch=1`。纯桌面窄窗口（指针正常）
刻意不算。加 `?touch=1` 强制显示。

## 自定义关卡上传被拒

| 状态行提示 | 含义 | 解决 |
|------------|------|------|
| `关卡文件「…」格式错误（需要数字 id 和 events 数组）` | `id` 缺失/非数字，或没有 `events[]` | 补 `"id": 91` 和 `"events": [...]` |
| `关卡「…」引用了未知怪物「…」` | 事件里怪物 id 打错 | 用 `data/enemies.json` 里的 id |
| `关卡「…」使用了未知编队「…」` | `formation` 值非法 | single / lineV / lineH / stagger / scatter 之一 |
| `Unexpected token …`（浏览器 JSON 报错） | 文件不是合法 JSON（尾逗号、注释、弯引号） | 用 JSON 校验器过一遍；模板 `_help` 里有结构示例 |
| 上传成功但没有 Boss | 没有 `boss` 事件的关卡能玩但永远过不了 | 最后加一条 `{ "t": …, "boss": "boss1" }` |

## 游戏感觉不对

| 症状 | 原因 | 解决 |
|------|------|------|
| 每按一次射击只发一轮 | 默认点射行为 | 设置 ⚙ → 自动连发 ON 恢复按住连射 |
| 标准档以上打不出子弹 | 弹药打空（HUD 显示 0）——扳机是干的 | 击杀回收弹药；下一关发新弹药；或换轻松档（无限） |
| 瞄准虚线不见了 | ◎ 道具的 20 秒时限到了（或坠机失效） | 它是拾取物不是设置——再捡一个 ◎ 十字准星即可 |
| 游戏自己暂停了 | 游戏中打开了设置，或标签页被切走 | 设计如此；「继续」从停止处精确恢复 |
| 画面发虚 | 非整数缩放 / 浏览器缩放 | 画布会按整数像素倍自适应；把浏览器缩放重置（Cmd/Ctrl+0） |
| 最高分变成 0 | localStorage 被清/被禁（隐私模式、清除站点数据） | 游戏会静默继续；其他功能不受影响 |

## 键盘没反应

- 先点一下页面让它拿到焦点（刚加载完尤其常见）。
- 方向键/空格在滚动页面：游戏只在 playing 状态调
  `preventDefault()`——确认游戏真的在进行中，而不是停在开始界面。
- 输入法处于组合输入状态会吞键——切到英文直通输入。

## 报 Bug

[提 Issue](https://github.com/petrel2015/space-impact/issues)，附：
浏览器 + 版本、操作系统、完整 URL 与参数、复现步骤、期望 vs 实际。
