# 常见问题

English version: [FAQ](../en/faq.md). 遇到故障先看
[故障排查](./troubleshooting.md)——本页回答的是范围与设计取舍类问题。

## 这是诺基亚原版游戏或模拟器吗？

都不是。这是原创复刻：所有精灵是手写字符串网格，所有音效是合成方波，
所有代码都是为本项目编写的。不含诺基亚 ROM、固件或原始资产——它是
对 3310 经典手感的致敬。

## 诺基亚 3310 屏幕是 84×48，为什么这里是 144×80？

照搬 84×48 对 27 种怪物和 Boss 弹幕来说太挤了。144×80 保留了单色
LCD 的味道（以及整数倍大像素），又给设计留了呼吸空间。触屏手机竖屏
时场地更高：144×128。

## 能离线玩 / 安装成 App 吗？

不支持。没有 service worker 和 PWA manifest，页面每次加载都要
fetch 数据包，所以（重新）加载时需要服务器可达。已加载的标签页内，
游玩不再需要网络。

## 不写代码能加关卡、加怪物吗？

能，这正是设计目标。怪物和关卡都是 JSON。两条路：

- **不动仓库：** 开始界面 → 下载关卡模板 → 编辑 → 上传关卡 JSON →
  立刻开玩（[做法](./usage.md#自定义关卡)）。
- **永久新增：** 在 fork 里改 `data/enemies.json` /
  `data/levels/*.json`，跑 `node test/data-test.js`
  （[做法](../../README.zh.md#扩展游戏)）。

只有全新的移动方式需要引擎侧加一个小原语（`js/behaviors.js` 里一个
函数）——其余一切都是数据。

## 为什么弹药是有限的？

从标准档开始的有限弹药是难度设计的一部分：它让瞄准虚线和子弹对消
有了意义。轻松档弹药无限；所有限弹药档位击杀都有回收。见
[难度与弹药设计说明](./features/difficulty-and-ammo.md)。

## 游戏为什么自己暂停了？

两种刻意为之的情况：你在游戏中打开了顶栏设置弹层（跑局中途改难度
不公平），或标签页被切到后台（visibilitychange）。两者都从停止处
精确恢复。

## 第 14 关打完会怎样？

战役回到第 1 关循环，敌人整体变强——每圈 HP +40%、速度 +12%、开火
更快——而你的分数、火力等级、导弹和大招能量全部保留。这是一场无尽
的分数追逐。

## 最高分存在哪里？

存在你浏览器的 `localStorage`（键 `si-hiscore`），按站点隔离。不会
发送到任何地方；清除站点数据即重置。完整存储表见[隐私](./privacy.md)。

## 支持手柄吗？

不支持——只有键盘和触屏。代码里没有 Gamepad API。

## 支持哪些浏览器？

任何现代浏览器（Chrome/Edge/Firefox/Safari 一类）——游戏用到
Canvas 2D、WebAudio、`fetch`、`localStorage`、Pointer Events 和
`matchMedia`。已在 Chromium 系浏览器验证；不支持旧版 IE。

## 游戏免费吗？代码能复用吗？

[在线版](https://petrel2015.github.io/space-impact/)免费游玩。代码
**尚无许可证**，意味着默认保留所有权利——复用前请与维护者沟通
（开 Issue）。

## `?demo=1` 是什么？

演示模式：一个自动驾驶 AI 通过与真人完全相同的输入管线开飞机
（同样的输入对象形状、同样的引擎步进）。它让游戏能在橱窗里自己
展示自己——也顺便证明输入路径是统一的。需配合 `?autostart=1`。
