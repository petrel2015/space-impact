# 《归途》设定集 · The Way Home

这是 Space Impact 五关战役《归途》的设定集（lore book）。每个关卡对应一个单元（`level-01.md` ~ `level-05.md`），像剧集一样讲完一段回家之旅：背景、冲突、高潮、本单元的怪物档案与 Boss 情报。关卡数据文件通过 `lore` 字段指向对应单元：

```json
{ "id": 1, "difficulty": 1.0, "lore": "docs/lore/level-01.md", "events": [ ... ] }
```

`lore` 是纯文档字段，引擎编译时忽略；设定集是关卡重构时的**内容基准**（敌人池、旁白、节奏都以这里为准）。

## 世界观

巡逻舰「信天翁号」在例行航线遭遇超空间风暴，被抛到 71,000 光年外的未知星区。曲速核心受损，无法一次跳回——唯一的办法是收集散落的**四块虫洞信标**，沿风暴残迹一段一段跳回家。

每个星域的出口都有守关者：击败 Boss，取回信标，开启下一段跃迁。五个单元，五段航程，一集一个星域，一集一个 Boss。

## 生态分组规律（设定集的第一原则）

敌人不是随机池子，**每种敌人有生态归属，一种只在一种星域出现**：

| 星域类型 | 成员 | 出现逻辑 |
|---|---|---|
| 自然灾害 / 穴居生物 | 陨石、蝙蝠（岩缝矿蝠）、蝠鲼（星尘鲼） | 碎石带里只有石头，和住在岩缝里以矿物为食的生物 |
| 虫族巢穴 | 黄蜂（掠袭蜂）、毒刺（毒刺蜂）、追踪者（护巢雄蜂） | 领地虫群：快速扰敌、带刺射击、死咬护巢 |
| 机械遗迹 | 侦察机（坟场巡逻机）、立方体（哨戒平台）、陀螺（防御矩阵）、蜘蛛（维修蜘蛛） | 百年前的自动守卫，只认旧敌我识别码 |
| 有组织军队 | 炮手（拦截炮艇）、轰炸机、螃蟹（布雷蟹艇）、鞭击者（狙击艇）、堡垒（移动要塞） | 掠夺者舰队——整支舰队都是抢来的 |
| 时空乱流（仅 EP05） | 上述混合，**按波次分段** | 虫洞风暴把沿途星域碎片吸进了同一条走廊 |

Boss 同理：EP02 蜂后产卵、EP03 主脑放巡逻机、EP04 旗舰放驯养兵蜂、EP05 利维坦放回收蛛——Boss 召唤的杂兵必须符合它自己的生态。

## 命名约定

- 怪物标题写作 `图鉴名「本单元身份」`，如 蝙蝠「岩缝矿蝠」。图鉴名来自 `data/codex.json`，单元身份是它在《归途》里的设定角色；两者都保留。
- 单元标题格式：`EPxx · 中文名 English Name`，与横幅图上的角标一致。

## 配图

- `images/foe-*.png` — 怪物档案头像（单元主题色点阵像）。
- `images/banner-l*.png` — 每单元一张像素横幅（主题配色 + 敌阵 + Boss + 单元角标）。
- 全部由 `node test/make-lore-images.js` 从 `js/sprites.js` 的点阵数据生成，零依赖、可重跑；改了配色或构图请改脚本后重新生成，不要手改 PNG。

## 开发路线图（设定集 → 关卡落地）

1. **重排关卡数据**：`level1.json`~`level5.json` 按设定集重写（敌人池锁定、节奏表落地、挂 `lore` 字段）；原 6~14 关的素材折叠进五关后下架（关卡在 git 历史可寻回）。
2. **Boss 召唤物对齐生态**：boss2 的 `spawn drone` → `spawn wasp`（产卵）；boss3 的 `spawn chaser` → `spawn drone`（放巡逻机）。boss4 放 wasp、boss6 放 spider 与设定一致，不动。
3. **旁白系统**：关卡开场/通关各一条旁白（文案已在各单元「游戏内文案」小节），i18n 双语，渲染为关卡首尾的旁白条。
4. **分关背景主题**：render/theme 按关卡切换背景与星色，五套配色取自各单元横幅。
5. **图鉴联动**：codex 每只怪物加「栖息地」标签（数据源 `codex.json` 加字段，UI 一行小字），呼应生态分组。
6. **存档兼容**：14 关压缩为 5 关后，检查 `save.js` 关卡进度快照的收缩/映射策略。
7. **收尾**：跑 `node test/data-test.js` 与图鉴 UI 测试；难度变体 boss（`boss2b/4b/5b/6b`）未编入五关，留给二周目或无尽模式。
